# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Commands
- Full regression gate: `./scripts/regression-gate.sh` (or `make gate`)
- Run single test: `xcodebuild test -project OrangeNote.xcodeproj -scheme OrangeNote -destination 'platform=macOS' -only-testing:<TestClass>/<testMethod>`
- Regenerate Xcode project: `xcodegen generate` (always regenerate after editing `project.yml` or adding files)
- Rust tests: `cargo test --workspace`

## Non-Obvious Project Conventions
- **Version Source of Truth**: App version is defined in `project.yml` under `CFBundleShortVersionString`. `OrangeNote/Info.plist` is regenerated by XcodeGen.
- **Dynamic Localization**: macOS SwiftUI does not switch bundle strings dynamically via `Bundle.main` / `LocalizedStringKey`. All UI views must use `L10n.string(...)` / `LocalizedText` from `OrangeNote/Helpers/LocalizationHelper.swift`.
- **Sandbox Security Scopes**: App Sandbox uses `user-selected.read-write`. Always wrap filesystem access for user-selected paths with `SecurityScopeHelper.withSecurityScope`.
- **Export Schema**: JSON exports must use `CanonicalTranscriptionSerializer` (v1 schema with metadata) from `OrangeNote/Persistence/`.
- **FFI Boundary & Job Guards**: Swift `Task.cancel()` does not interrupt blocking Rust FFI. View models must use `jobID` / `isBusy` verification guards to prevent stale updates.
- **Batch Processing**: Sequential processing (Metal GPU constraint); atomic file writes via `AtomicFileWriter` using `renamex_np(RENAME_EXCL)` to prevent overwrite.
